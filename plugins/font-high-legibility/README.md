# Font: High legibility (`font-high-legibility`)

The High legibility font look (ADR-0107): Atkinson Hyperlegible Next. A `typeface@1` plugin.

- **Atkinson Hyperlegible Next.** 2.001, 200 800 variable upright, `AtkinsonHyperlegibleNext-wght.woff2` from <https://github.com/googlefonts/atkinson-hyperlegible-next/tree/7925f50f649b3813257faf2f4c0b381011f434f1>. Unmodified.
  Reserved Font Name: none.
- **Licence.** SIL Open Font Licence 1.1; each upstream text is `OFL.txt` beside its font.
- **Seeds** (once, app-owned): the fonts, their `OFL.txt` files and `fonts.css` under
  `web/static/fonts/`.
- **`preview-tokens.json`** holds the four stacks (`font_heading`, `font_body`, `font_data`,
  `font_label`) the Look step paints.
- **Skill.** `skills/font-high-legibility/SKILL.md` and its examples: linking `fonts.css`, preloading the body
  file and setting the four `--font-*` properties.
